# 多肽设计工作台

工作台提供参数配置、流程预览、一键运行和结果查看，支持统一配置 36 项关键参数及筛选阈值，并调度 11 个工程阶段。

## 1. 安装与启动

以下命令均在仓库根目录执行。工作台使用 Python 3.10 或以上；计算任务所需的 Linux GPU 环境、三个 Conda 环境及模型获取方式见 [项目 README](../README.md)。

```bash
python -m pip install -r environment/requirements-workbench.txt
python workbench.py --port 8081
```

通过 Cursor Remote SSH 连接服务器时，在“端口（Ports）”面板转发 `8081`，点击浏览器图标打开工作台。

使用其他 SSH 客户端时，可在本机执行端口转发：

```bash
ssh -L 8081:127.0.0.1:8081 user@server
```

然后在本机浏览器访问 `http://127.0.0.1:8081`。

## 2. 使用流程

1. **创建任务**：在左侧填写任务名称，默认为“NTSR1 靶向肽设计”。
2. **参数配置**：打开顶部“参数配置”，调整生成数量、肽长范围、筛选阈值及最终候选数量，点击“保存参数”。默认值读取项目当前配置。
3. **流程预览**：查看当前参数对应的执行计划，不启动模型计算。
4. **一键运行**：调用 `run_pipeline.sh`，逐阶段读取已有结果并执行缺失阶段，同步显示进度和运行日志。
5. **运行结果**：选择任务，依次查看运行日志、流程总览和候选结果。支持按编号或序列检索候选，查看结构指标、口腔酶切风险及主要风险来源，下载候选 CSV、对应 PDB 和运行日志。

工作台一次执行一个任务。酶切风险作为补充注释，不改变候选排序。

代码版初始不包含筛选结果，可以先配置参数并预览流程；实际计算前需按 [输入说明](INPUTS.md) 准备模型和数据。

## 3. 参数与结果保存

|内容|位置|
|---|---|
|筛选参数|`config/*.json`|
|参数修改前的备份|`work/workbench/config_backups/`|
|任务记录、配置快照和工作台日志|`work/workbench/<任务编号>/`|
|各阶段筛选结果|`work/` 下对应阶段目录|
|阶段计算日志|`work/launcher/logs/`|

保存的参数用于缺失阶段的计算；已有结果继续复用。按新参数重新计算完整流程时，在终端指定新的结果目录：

```bash
bash run_pipeline.sh --work-dir work/new_run
```

## 4. 更新部署

首次部署将仓库代码复制到服务器，按上述命令安装依赖并启动。更新已有部署时，替换工作台和启动器相关文件，保留服务器上的配置、模型及筛选结果。重启工作台后，在浏览器按 `Ctrl+Shift+R` 刷新。
