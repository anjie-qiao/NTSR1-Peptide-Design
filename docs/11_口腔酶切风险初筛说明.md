# 阶段 11：口腔酶切风险注释

本阶段是可审计的序列风险补充，**不是训练模型、MD、自动选肽或耐酶切实验结论**。

## 输入与运行

酶切统计快照需单独准备，格式见 [输入准备说明](INPUTS.md)。

输入：阶段 10 最终 CSV（必须有唯一 `candidate_id` 与大写标准氨基酸 `sequence`，长度至少 8），2026-09-29 MEROPS 快照和阶段 11 配置。默认配置要求 100 条；全流程运行时，`main.py` 或 `run_pipeline.sh` 按实际候选数量生成运行配置，调整预期数量。

```bash
python pipeline/11_oral_proteolysis_filter.py --config config/11_oral_proteolysis_filter.json
```

只需 Python 标准库，不访问网络，不启用 wandb。

## 算法及决策口径

1. 对覆盖完整 P4–P4′ 的潜在断键计算五个 MEROPS profile 的位点分数。每列加伪计数 1，以列最大频次归一化后取几何均值；是相对偏好分数，**不是校准后的切割概率**。
2. 额外记录牙龈蛋白酶 RgpA/RgpB 的 R 后、Kgp 的 K 后基序，以及人 DPP4/牙龈卟啉单胞菌 DPPIV 的 N 端 XP/XA 偏好。DPP-IV 的解释依赖游离 N 端，目前端基化学状态未核实。
3. 按牙龈蛋白酶、DPP-IV、中性粒细胞弹性蛋白酶、组织蛋白酶、MMP 五类酶家族汇总。各矩阵先单独按批内分位数比较；组织蛋白酶和 MMP 分别采用家族内较高 profile 分位数，并再次重排以避免双矩阵家族权重偏高。五类家族分位数等权平均后再次按批内分位数分为相对低/中/高（33.33%/66.67% 分界）。
4. **所有候选原样保留且顺序不变**。输出不给阶段 10 分数加权、不替换变体、不自动选出五条肽。专家可把这项注释与结构质量、合成可行性、实际 MD 和实验信息一起讨论，但这不属于当前自动排序。

仅一条的小示例适合核验程序，不适合解释相对风险高低；不同候选批次的分位数不能横向比较。

数值策略：用 `math.fsum` 求和，分位数比较前保留 12 位小数，避免浮点舍入误差拆开应并列的分数。

## 输出（work/11_oral_proteolysis_filter/）

- `oral_cleavage_risk.csv`：候选序列、相对等级/分位数、主要风险来源、范围与证据覆盖。
- `evidence/oral_cleavage_metrics_all.csv`：候选级全指标。
- `evidence/enzyme_profile_summary.csv`、`profile_window_scores.csv`、`motif_cleavage_sites.csv`：逐酶、逐窗口及规则位点明细。
- `oral_cleavage_manifest.json`：输入哈希、参数、限制及不参与排序的声明。
- `口腔酶切风险初筛结果.md`：可读说明。

正式 `results.csv` 由 `main.py` 以 `candidate_id` 合并阶段 10/11；导出前强制检查 ID、序列和顺序完全一致。

## 局限

MEROPS 统计混合不同底物、物种和测定条件；不代表单一牙周组织环境。完整 8 位窗口无法覆盖靠近末端的部分断键，未将未覆盖位点当作安全位点。不模拟酶浓度、温度/pH、肽构象可及性、受体保护、非天然氨基酸、D 构型或端基修饰。相对低风险不等于“抗酶切”，需要实测验证；固定规则与人工文献判断存在不确定性。
